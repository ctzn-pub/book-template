## How it's structured

The sidebar is generated from `lib/docs-toc.ts`: a list of **sections**, each
with **pages**. Edit that file to shape your sidebar. Every page is an MDX file
under `app/docs/<slug>/`, wrapped in `<DocsShell>`.

## What you get

- An always-open sidebar on desktop; a slide-in drawer on mobile.
- The current page highlighted in the sidebar.
- Optional prev/next links at the foot of each page (in sidebar order).
- The same components, typography, and five switchable themes as the other
  formats — try the **Theme** button, top-right.
